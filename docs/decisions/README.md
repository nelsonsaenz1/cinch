# Decision log

Things that were decided, and things that went wrong, with enough of the
reasoning that the next person does not have to rediscover it.

An entry earns its place here when the *reasoning* is worth more than the diff —
a constraint discovered by measurement, a trade deliberately accepted, or a
failure whose cause is not visible in the code that fixed it. Ordinary changes
belong in commit messages, and the commit messages in this repository are
written to carry them.

Entries are append-only. When a decision is reversed, add a new entry that says
so and link back; do not edit the old one into agreement with the present.
