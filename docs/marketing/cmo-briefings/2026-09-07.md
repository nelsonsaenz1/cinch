### 8.3 Falsification — is the first-item step change caused by audit ship 6?

The claim: first-item conversion rose on 09-07 and is **not** attributable to audit ship 6, which
shipped at 20:14Z. The obvious rival explanation is that the ship caused it. Second,
differently-shaped query — split today's cohort at the ship time:

```sql
with cls as (
  select u.id, u.created_at ca,
    case when lower(coalesce(u.email,'')) like '%cinchstyle.com'
              or lower(coalesce(u.email,'')) = 'demo@cinch.app' then 'internal'
         when lower(coalesce(u.email,'')) like '%saenz%'        then 'family'
         when lower(coalesce(u.email,'')) like 'cinchbounce%'   then 'gate'
         else 'real' end k
  from auth.users u)
select case when c.ca < '2026-09-07 20:14:00+00' then 'before ship' else 'after ship' end arm,
       count(*) signups,
       count(*) filter (where exists (
         select 1 from items i
         where i.user_id = c.id and i.created_at < c.ca + interval '6 hours')) first_item_6h
from cls c
where c.k = 'real' and c.ca >= '2026-09-07' and c.ca < '2026-09-08'
group by 1;
```

```
 arm          | signups | first_item_6h
 before ship  |    4    |      3          → 75%
 after ship   |    5    |      5          → 100%
 (prior 16 days, same 6-hour basis)        → 14 of 37 = 38%
```

**Result: the lift is present on both sides of the ship.** Audit ship 6 cannot be credited and the
cause is unattributed. Recorded as **HYPOTHESIS**. Candidate causes, none tested: the arriving
cohort is different (East-Coast concentrated, §17.1); the promotional text set 09-01 is selecting
for intent; or **9 is a small number and this is variance.** Rerun in three days.

**Robustness against basis-shopping:** on the looser *ever* basis the same comparison reads
**8 of 9 = 89% today vs 18 of 37 = 49% prior** — which favours the prior period if anything, since
those 37 have had up to sixteen days. Both bases give the same direction, and both were re-derived
by a second items-side `group by` that does not use `EXISTS`, returning identical figures.

**17.1 — the featuring hypothesis for the 09-05/06 surge is dead, and it was mine.**
The 09-06 briefing offered as circumstantial evidence for a category or featuring placement that
"5 of 16 arrivals were non-US against a 94%-US baseline." Two independent reads kill it: A47's

```sql
select case when c.ca >= '2026-09-05' then 'since 09-05' else 'before 09-05' end period,
       count(*) signups,
       count(*) filter (where p.time_zone like 'America/%') us_like,
       count(*) filter (where p.time_zone = 'America/New_York') new_york
from cls c join profiles p on p.user_id = c.id
where c.k = 'real' group by 1;
```

```
 period       | signups | us_like | new_york
 since 09-05  |   23    |   19    |   13
 before 09-05 |   33    |   25    |    5
```
