Cinch · Today screen · build reference
The Today state atlas
Every rendering the Today tab can produce, traced from src/app/(tabs)/index.tsx and the components it mounts. Full frames show screen-level states; detail cards show the plate’s interaction states; strips show the context-line permutations. Each rendering is annotated with the exact condition that triggers it, so an implementation can be checked state-by-state.

Rules the atlas encodes
One oxblood per screen. The accent fills a loved look and the stylist ✦ — buttons here are ink or outlined.
Honesty gates every sentence. No confirmation before the server confirms; no weather colophon without weather; no invented name; no rich-taste claim under 8 reactions; sync time is the query’s own dataUpdatedAt.
Geometry never jumps. Reserved status lines, non-unmounting pill slots, skeletons with the exact anatomy of what replaces them.
Errors are never empty states. isError → T-08; length 0 → T-04; offline → T-10/11 — three different screens for three different truths.
The stylist door never closes. Every state, full or reduced, carries the ✦ — 34pt circle, 44pt effective target.
Tab bar: Today / Closet / Plan / Explore (person.2 symbol — friends, their uploads, style news). Stylist and Profile have no tabs; they’re reached from the masthead chips only.
